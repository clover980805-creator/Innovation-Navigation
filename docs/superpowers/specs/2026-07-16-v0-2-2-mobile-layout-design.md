# V0.2.2 手机端双列布局与点击稳定性

## 目标

改善 Innovation Navigation 在手机浏览器中的工具入口体验。桌面与平板的整体视觉语言保持不变；仅调整手机端排版与卡片按压反馈。

## 已确认的设计

### 手机端布局

- 在视口宽度不大于 720px 时，六个工具卡片固定为两列、三行。
- 卡片高度、图标尺寸、标题区域和顶部标签沿用 x-navigation 的紧凑双列阅读节奏。
- 不修改背景、色调、玻璃材质、工具图标、标题、状态文案或卡片配色。
- 390px 与 414px 宽度应完整显示两列，卡片之间保留清晰间距；320px 仍保持两列，不退回单列。

### 交互反馈

- 复用 x-navigation 的卡片级按压语义：触摸按下时整张卡片轻微缩放，松开后平滑复原。
- 手机上的 `.service-art` 保持固定定位和无水平位移；不继承桌面 hover/focus 下的 `translateX(-50%)` 图标动画。
- 桌面 hover 与键盘 focus 保留卡片凸显效果，但手机触摸不让图标上浮、平移或跳位。
- 遵循 `prefers-reduced-motion`，在用户请求减少动效时取消按压过渡。

## 实施边界

- 修改根目录与 `production/` 的 CSS，保持两份发布样式一致。
- 更新静态布局测试，覆盖手机两列和“图标不漂移”的选择器约束。
- 使用本地浏览器在 320px、390px、414px、768px 和 1440px 进行视觉验证。
- 不修改任何应用链接、业务逻辑、VPS、部署配置或站点色彩。

## 验收标准

1. 手机端每行稳定显示两个应用，共三行。
2. 点击任一应用时，整卡有轻微按压反馈，图标位置不发生水平或垂直漂移。
3. 现有桌面三列布局和色调保持不变。
4. 根目录与 `production/` 发布包的样式一致，静态测试与视觉检查通过。
